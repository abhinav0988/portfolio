Selected projects

Personal portfolio project · Distributed systems

RideFlow — Real-Time Ride Platform

Node.js · TypeScript · PostgreSQL · Redis · RabbitMQ · Socket.IO
GitHub ↗

Backend-focused ride platform covering nearby-driver discovery, race-safe acceptance, and at-least-once messaging across multiple Socket.IO servers.

TypeScript PostgreSQL Redis GEO RabbitMQ Socket.IO Jest Testcontainers
  • Nearby-driver discovery with Redis GEO and 30-second presence expiration, with Socket.IO instances connected through the Redis adapter.
  • Race-safe ride acceptance using Redis SET NX locking and a PostgreSQL conditional update so only one driver can accept an offered ride.
  • Transactional outbox with PostgreSQL idempotency, RabbitMQ publisher confirms, retries, a dead-letter queue, and idempotent consumers for at-least-once delivery.
  • Concurrency and messaging tests with Jest and Testcontainers, plus GitHub Actions CI for the distributed flows.
Personal portfolio project · v1.0.0

Shortify — URL Shortener & Analytics

Fastify · TypeScript · MongoDB · Redis · React
GitHub ↗

URL shortener with unique short codes under concurrent creates, cache-aside redirects, shared rate limits, and click analytics.

Fastify TypeScript MongoDB Redis React Jest Vitest
  • Base62 codes and custom aliases on Fastify, with MongoDB unique indexes and bounded retries so short codes stay unique under concurrent requests.
  • Redis cache-aside redirects with expiration-aware TTLs, MongoDB fallback when Redis errors, and cache invalidation when a link changes.
  • Shared fixed-window rate limits via atomic Redis Lua scripts, plus click analytics built on MongoDB aggregations and atomic counters.
  • 99-test suite covering backend and frontend with Jest, Vitest, and Testcontainers, and GitHub Actions CI for typecheck, tests, and production builds.
